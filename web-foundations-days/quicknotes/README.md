QuickNotes is a simple note-taking web application built with HTML, CSS, and JavaScript. It allows users to create notes, organize them into Personal, Work, and Study categories, search through their notes, delete notes, and keep their notes saved in the browser using localStorage. The application is designed with a clean, responsive interface that works on both desktop and smaller screens.

Features
Add new notes.
Organize notes into Personal, Work, and Study categories.
Search notes by their text.
Delete individual notes.
Validate notes before adding them.
Prevent notes longer than 200 characters.
Display the total number of notes.
Save notes using browser localStorage.
Restore saved notes when the page is reopened.
Display the date and time when each note was created.
Responsive design for smaller screens.
Category-specific styling for notes.
